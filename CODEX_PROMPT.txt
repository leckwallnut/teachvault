## THE GAME: "Map It!" (Information Gap Navigator)

**Concept:** A pair-work ESL game where Student A sees a map with a route marked, and Student B must draw the same route by listening to Student A's directions. The game runs entirely in the browser — no server needed.

**How it works:**
1. The game displays a stylized town map (drawn with HTML5 Canvas — no external images needed) with 8-10 named landmarks (e.g., "School", "Park", "Library", "Hospital", "Supermarket", "Bus Station", "Cinema", "Restaurant", "Bank", "Post Office")
2. A random route is generated connecting 4-5 landmarks in sequence
3. PHASE 1 — "Study" (60 seconds): Both students look together. Student A's screen shows the route overlaid on the map (red dashed line with numbered stops). Student B's screen shows only the blank map with landmarks. They study the layout together.
4. PHASE 2 — "Navigate" (120 seconds): Student A gives verbal directions ("Go north from the school, turn left at the park..."). Student B clicks landmarks in the correct order on their map to trace the route. A timer counts down.
5. PHASE 3 — "Reveal": The correct route is shown. Student B's route is compared to the correct one. Score: 20 points per correct landmark in the correct position. Bonus 20 points for perfect match.
6. PHASE 4 — "Swap": Roles reverse with a new random route. Student B gives directions, Student A draws.
7. Final score screen with both rounds.

**Technical requirements:**
- Single HTML file: `map-it.html` in the repo root
- ALL CSS and JS inline (no external dependencies except Google Fonts — use Fraunces + Manrope to match the existing design)
- Match the EXACT design language of the existing game.html — same CSS variables, same color palette (--color-bg: #f9f3e6, --color-blue-deep: #2f3e46, --color-gold: #f2c66d, etc.), same border-radius, same shadows, same transitions
- The map should be an HTML5 Canvas element with a charming hand-drawn style town map (draw roads, building icons, trees, a river — all procedurally with canvas drawing functions)
- Landmarks should be clearly labeled text labels on the map
- The route overlay should be a red dashed line connecting landmarks with numbered circles at each stop
- Student B's drawing should be a blue line that follows their clicked landmarks
- Responsive design — works on desktop and tablet
- Include a "New Game" button that generates a fresh random map layout and route
- Include a difficulty selector: Easy (4 landmarks, 90s), Medium (5 landmarks, 120s), Hard (6 landmarks, 150s)
- Sound effects using Web Audio API (simple beeps — no audio files needed)
